# FlyBrain Arena

Интерактивная образовательная модель Drosophila. Запуск: `npm start`, затем http://127.0.0.1:5173. Проверки: `npm test`. Зависимости не требуются; Node.js 22+.

## Управление

- Еда, барьер, касание, движущийся объект, удаление: кнопки или 1–5, затем клик по арене.
- Свет, хищник, температура: панель среды.
- Пробел: пауза. На паузе доступен один шаг 1/60 с.
- Клавиатура: Tab до арены, стрелки перемещают курсор, Enter применяет инструмент.
- Сброс возвращает начальное состояние и seed; очистка удаляет объекты и хищника.

## Научные границы

Это не эмуляция всего мозга и не модель с экспериментально установленной точностью. Сенсорные функции, постоянные времени, моторное управление и реакции на температуру — предположения. Моторные каналы не отождествлены с индивидуальными нейронами. Координаты и скорость условные, активность безразмерная (0–1).

В `dist/connectome.json` сохранён один проверенный тип-тип фрагмент MaleCNS v1.0: LC4 → DNp01, 6362 контакта суммарно, 126 клеток LC4 и 2 DNp01 в каталоге. Сумма контактов прочитана из атрибута `title="∑ connections: 6,362"` строки `d4` раздела Outputs страницы LC4, а не из округлённого среднего 50.5. Дата проверки: 17.09.2026. Зрительный канал использует `ln(1+6362)/10` как **произвольно выбранную нормировку** агрегированного анатомического веса. Использование этого фрагмента в избегании угрозы — демонстрационное допущение. Нельзя интерпретировать получившееся поведение как проверенное предсказание биологии.

Пять каналов сглаживаются с τ=0.12 с, DNp01 с τ=0.18 с. Сигнал DNp01 участвует в конкуренции с пищей и светом. Моторная разность задаёт угловую скорость. Барьеры имеют приоритет; хищник — кинематический источник зрительного стимула, проходящий через барьеры (это не второй физический агент). Чувствительность к угрозе изотропна; сектор у мухи обозначает только направление движения. Температура однородна, поэтому термотаксис не моделируется.

Полный коннектом не загружен. Live neuPrint API не подключён. Для воспроизводимого обновления связи через API есть `scripts/export_neuprint.py` (личный токен только в переменной окружения, не во frontend). Результат записывается отдельно для сверки, автоматически встроенные данные не заменяет.
